# 企业电价查询工具

这是一个纯静态、单文件运行的企业电价查询页面。输入企业名称后，可查看：

- 2026 年原签约价差及其在全省样本中的位置；
- 2026 年 9 月限价后，按 `+14 元/兆瓦时`封顶计算的结算价差；
- 限价后结算价差相对 `+14` 上限的价格优势；
- 2024—2025 年历史记录及资料来源。

页面已适配手机端：搜索按钮和输入框采用触控尺寸，结果卡片会随屏幕宽度重排，明细表格可横向滑动查看。建议使用最新版微信内置浏览器、Edge、Chrome 或 Safari。

## 文件说明

- `index.html`：查询工具本体，数据、页面样式和查询逻辑均已内嵌。
- `.nojekyll`：让 GitHub Pages 直接按静态文件发布。
- `LICENSE`：代码使用许可，不代表其中的数据可以公开传播。

无需安装软件，也不需要服务器。直接双击 `index.html`，或通过 GitHub Pages 访问即可。

## 上传到 GitHub

1. 在 GitHub 新建一个仓库。
2. 建议先选择 **Private**，不要勾选自动创建 README、许可证或 `.gitignore`。
3. 进入新仓库，选择 **Add file → Upload files**。
4. 把本文件夹中的所有文件拖入上传区域并提交。

如果仓库用于公开发布，请先阅读下方的“数据安全提示”。

## 开启 GitHub Pages

1. 打开仓库的 **Settings → Pages**。
2. 在 **Build and deployment** 中选择 **Deploy from a branch**。
3. Branch 选择 `main`，目录选择 `/(root)`，然后保存。
4. 等待 GitHub 完成部署，Pages 页面会显示访问地址。

请注意：GitHub Pages 发布的网站是公开的。即使仓库设置为 Private，也不要把当前含业务数据的版本直接发布成公开网站。

## 数据安全提示

`index.html` 不只是网页外壳，里面还嵌入了原始业务数据。数据中可能包含企业名称、签约信息、联系方式和地址等内容。上传到公开仓库或启用公开 Pages 后，任何访问者都可能下载并解析这些数据。

建议：

- 内部使用时，将仓库保持为 Private，并严格控制协作者；
- 没有明确公开授权时，不要开启公开 GitHub Pages；
- 对外发布前，另行制作脱敏版，移除联系方式、地址、户号以及不需要公开的原始字段；
- 仓库权限和 Pages 可见性应以 GitHub 当前账户方案和页面提示为准。

## 分析口径

- 原签约价格水平：将 2026 年 3 月原合同价差与全省同期样本比较。
- 限价后价格优势：只将 9 月结算价差与 `+14 元/兆瓦时`上限比较，不再与市场样本比较。
- 原价差超过 `+14` 的部分，按用户补充口径，自 2026 年 9 月起统一按 `+14 元/兆瓦时`封顶结算。
- 9 月限价口径来自用户补充信息，尚未由正式政策文件核验。

页面结论用于资料整理和初步分析，不替代正式合同、结算单及政策文件。

## 更新工具

收到新版 `index.html` 后，直接替换仓库根目录中的旧文件并提交。GitHub Pages 通常会自动更新。
